# Changelog for the Vestertopian Learned League BWA Search Debiaser

This is the changelog for the [Vestertopian Learned League BWA Search Debiaser](https://github.com/rwv37/vllbwasdebiaser). Releases are listed in temporal order, with the most recent on top.

# Releases

## Version 1.0.1 (2025-12-17)

### 1.0.1: Works on multiple flavors of URLs from the Learned League website

The Learned League website supports URLs both like "https://learnedleague.com/" and those like "https://www.learnedleague.com/". Version 1.0.0 of the Vestertopian Learned League BWA Search Debiaser only works on the former, not the latter. Version 1.0.1 works on either.

## Version 1.0.0 (2025-11-19)

### 1.0.0: Nonexistence fixed

Previously, the Vestertopian Learned League BWA Search Debiaser did not exist. Version 1.0.0 resolves this issue.
